# Infinite-Chump-Save-File-Editor

Press SET DIRECTORY, and choose which directory you want your run.save to be generated at. If you want it inside the game files, it will be " %Appdata%/LocalLow/PICKLEHOUSE/INFINITE CHUMP ".

Then, just change around values, if you know the game you should understand every parameter. When you are done press GENERATE FILE.

You can press IMPORT SAVE to import a file and as long as its valid it should read all the data into each slot.
